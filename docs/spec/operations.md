## 1. 테스트 계획

### 수용 테스트 시나리오 (Given / When / Then)

- **시나리오 1: 상세 조건(지하철 노선번호 및 버스 정류소명) 지정 후 경로 검색 및 저장 (SCR-02 -> SCR-01)**
  - **Given**: 사용자가 `/search` 페이지에 접속해 있다.
  - **When**: 지하철 역명 입력 후 노선번호를 선택하고, 버스 정류소명을 검색하여 정류소를 선택한 뒤 [저장하기] 버튼을 클릭한다.
  - **Then**: `/` (메인 화면)으로 이동하며, LocalStorage에 선택한 노선번호와 정류소명이 반영된 경로 카드가 표시된다.

- **시나리오 2: 상세 경로 내 정차역 및 노선/정류소명 확인 (SCR-03)**
  - **Given**: 메인 화면에서 경로 카드를 클릭하여 상세 페이지(`/route/route_1`)에 진입했다.
  - **When**: 상세 화면의 대중교통 구간별 노선번호와 정류소명, 정차역 목록 영역을 확인한다.
  - **Then**: 지하철 노선번호와 버스 정류소명이 정확히 표기되어 있으며 거쳐가는 모든 정차역 목록이 표시된다.

- **시나리오 3: 출발 타이밍 알림 푸시 (SCR-03)**
  - **Given**: 도보 소요 시간이 '7분'으로 설정되어 있고 알림 스위치가 'On' 상태이다.
  - **When**: 실시간 첫 탑승 차량 도착 남은 시간이 '7분' 이하가 된다.
  - **Then**: 브라우저 알림으로 `"[경로명] 지금 출발하세요! 첫 번째 탑승 교통수단 도착까지 7분 남았습니다."` 메시지가 발송된다.

- **시나리오 4: 스모크 테스트 경로 검증**
  - **Given**: 앱이 Vercel에 배포되었다.
  - **When**: GET `/`, GET `/search`, GET `/route/route_1` 경로에 각각 접속한다.
  - **Then**: 세 경로 모두 200 OK 응답과 함께 해당 화면의 UI가 오류 없이 렌더링된다.
