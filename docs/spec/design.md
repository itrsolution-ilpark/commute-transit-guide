## 1. 화면과 주소(URL) 구성

### 화면 및 URL 구성

| 화면 ID | 화면 이름 | 경로(URL) | 주요 구성 요소 및 동작 | 비고 |
| --- | --- | --- | --- | --- |
| SCR-01 | 메인 대시보드 | `/` | - 상단 헤더: 타이틀 '출퇴근 길잡이', [경로 추가 +] 버튼<br>- 경로 카드 목록: 경로명, 복합 교통수단 뱃지(예: 🚇지하철 2호선 ➔ 🚌9000번), **출발 시각 ~ 예상 도착 시각**, 첫 차량 실시간 남은 시간, 알림 토글 스위치, 삭제 버튼<br>- 등록된 경로가 없을 시: 빈 상태 화면 | 스모크 테스트 대상 |
| SCR-02 | 경로 검색 및 추가 | `/search` | - 헤더: [뒤로가기] 버튼, '새 경로 추가' 타이틀<br>- **상세 검색 폼**: <br>  1. 지하철 검색: 역명 입력 후 연관된 **노선번호(예: 2호선)** 선택 셀렉트박스 제공<br>  2. 버스 검색: **정류소명(또는 정류소 번호)** 키워드 입력 후 리스트에서 정류소 선택 기능<br>- 설정 폼: 경로 별칭 입력 인풋, 도보 소요 시간 슬라이더<br>- 하단 고정 [경로 저장하기] 버튼 | 스모크 테스트 대상 |
| SCR-03 | 경로 상세 및 수정 | `/route/:id` | - 헤더: [뒤로가기] 버튼, [수정/저장] 버튼<br>- 실시간 요약 카드: **출발 시각 / 도착 시각**, 현재 차량 위치 및 남은 시간<br>- **상세 경로 구간 리스트**: 도보 구간 ➔ 지하철 구간(지하철역명 + **노선번호**, **정차역 전체 보기 접기/펼치기**) ➔ 버스 구간(**정류소명**, 버스번호, **정차역 전체 보기 접기/펼치기**)<br>- 하단 [경로 삭제] 버튼 | 스모크 테스트 대상 (`/route/route_1`) |

### 주요 UI 컴포넌트 규격
- **헤더 바**: 높이 `56px`, 배경 `#2563EB`, 타이틀 폰트 `18px Bold` (`#FFFFFF`)
- **경로 카드**:
  - 배경 `#FFFFFF`, 테두리 `1px solid #E2E8F0`, 둥근 모서리 `12px`, 패딩 `16px`
  - 시간 정보 강조: `#0F172A` (14px SemiBold, 예: `08:10 출발 ➔ 08:55 도착`)
  - 실시간 도착 시간 강조: `#10B981` (18px ExtraBold, 예: `3분 후 도착`)
  - 최소 터치 영역: 버튼/토글 높이 최소 `44px` 이상 유지

## 2. 디자인 가이드

### 디자인 시스템 명세
- **주요 색상 (Primary)**: `#2563EB` (인디고 블루 - 헤더, 주요 액션 버튼)
- **보조 색상 (Accent/Success)**: `#10B981` (에메랄드 그린 - 정상, 도착 예정 시간 강조)
- **경고/삭제 (Danger)**: `#EF4444` (레드 - 삭제 버튼, 에러 메시지)
- **배경 색상 (Background)**: `#F8FAFC` (연한 회색)
- **카드 및 레이어 (Surface)**: `#FFFFFF` (흰색)
- **기본 텍스트**: `#0F172A` (진한 텍스트), `#64748B` (서브 텍스트)
- **폰트**: Pretendard, system-ui, sans-serif
- **반응형 규격**: 모바일 퍼스트 기준 (390px ~ 768px 지원), 버튼 터치 영역 최소 `44px`x`44px` 이상
