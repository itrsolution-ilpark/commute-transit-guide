## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
- 사용자의 출퇴근 동선(출발지~도착지)에 맞는 버스·지하철 복합 대중교통 최적 경로, 출발/도착 시각, 상세 정차역 정보를 제공하고, 집에서 나갈 시점에 맞춰 브라우저 알림을 주어 바쁜 출퇴근길을 돕는 웹 서비스.

### 주요 가치
- 즐겨찾는 출퇴근 경로 저장 및 빠른 조회 (`LocalStorage` 기반)
- 수도권(서울/경기/인천) 버스 및 지하철 실시간 도착 예정 시간, 출발 시각, 예상 도착 시각 확인
- **복합 경로 추적**: 버스와 지하철을 환승하는 복합 경로 지원 및 상세 구간별 교통수단(버스/지하철) 아이콘·이름 표기
- **정차역 상세 보기**: 탑승부터 하차까지 거치는 모든 정차역 목록 시각화
- **출발 타이밍 알림 기능**: 실시간 남은 시간을 역산하여 집에서 출발해야 할 시점(도보 소요 시간 기준)에 브라우저 알림 전송

### 타겟 사용자
- 매일 정해진 버스·지하철 복합 환승 출퇴근 경로를 이용하며, 탑승 및 하차 타이밍을 정확히 맞추고 싶어 하는 직장인 및 학생

## 2. 사용자와 사용 시나리오

### 사용자 페르소나
- **직장인 김출근 (30세)**: 매일 아침 집에서 회사까지 버스와 지하철을 환승해 출근함. 집을 나서기 전 실시간 도착 정보를 보고 나가는 타이밍을 잡고 싶어 함.

### 사용자 시나리오
1. **경로 설정**: 사이트 접속 후 자주 가는 출발지와 도착지를 입력하여 브라우저에 저장한다.
2. **실시간 정보 확인**: 메인 화면에서 저장된 출퇴근 경로 카드를 누르면 현재 시각 기준 최적 경로와 다음 도착 차량의 남은 시간을 확인한다.
3. **새로고침**: 도착 정보는 30초마다 자동 갱신되거나 새로고침 버튼으로 갱신할 수 있다.

## 3. 기능 명세

### 핵심 기능 명세

| 기능 ID | 기능명 | 상세 동작 규칙 | 오류 처리 / 예외 케이스 |
| --- | --- | --- | --- |
| FEAT-01 | 경로 검색 및 등록 | - 키워드 검색: 출발지 및 도착지 입력 시 공공 API(또는 모의 데이터)를 통해 버스+지하철 복합 최적 경로 목록 반환<br>- 등록 항목: 경로 이름(예: '회사 출근길'), 출발지/도착지 명칭, **복합 교통수단 구간 정보(예: 도보 ➔ 지하철 2호선 ➔ 버스 9000번)**, 도보 이동 소요 시간 | - 검색 결과 0건 시: `"검색 결과가 없습니다. 출발지와 도착지를 다시 확인해주세요."` 안내 문구 노출<br>- API 응답 지연 시: 검색 인풋 내 로딩 스피너 표출 |
| FEAT-02 | 복합 경로 실시간 추적 및 시각 표시 | - 등록된 경로의 전체 **출발 시각** 및 **예상 도착 시각** 표시<br>- 상세 경로 내 각 구간별 **교통수단 아이콘 및 명칭(지하철/버스)** 명시<br>- 각 구간별 **모든 정차역(경유역) 목록**을 아코디언 또는 타임라인 형태로 펼쳐서 표시<br>- 실시간 남은 도착 시간 및 정거장 수 반영 | - API 완전 실패 시: UI 상단 `"실시간 정보를 불러오지 못했습니다. 잠시 후 다시 시도해주세요"` 토스트 노출 및 [재시도] 버튼 표시 |
| FEAT-03 | 출발 타이밍 알림 | - 브라우저 `Notification` API 사용<br>- 알림 조건: `(남은 도착 시간(분)) <= (설정한 도보 이동 시간(분))` 충족 시 단 1회 알림 발송<br>- 알림 문구: `"[경로명] 지금 출발하세요! 첫 번째 탑승 교통수단 도착까지 {X}분 남았습니다."` | - 알림 권한 거부(`Notification.permission === 'denied'`) 시: 화면 내 `"브라우저 알림 권한이 차단되어 있습니다. 브라우저 설정에서 허용해주세요."` 안내 배너 노출 |
| FEAT-04 | 경로 관리 (CRUD) | - `LocalStorage` 기반 생성, 조회, 수정, 삭제<br>- 메인 화면 카드에서 스와이프 또는 [삭제] 버튼 클릭 시 확인 모달 후 즉시 삭제<br>- 상세 페이지에서 경로명 및 세부 옵션 수정 가능<br>- 초기 기기 접속 시 안내용 복합 대중교통 기본 경로(`route_1`) 1건 자동 생성 | - 삭제 확인 창: `"정말 이 경로를 삭제하시겠습니까?"` 모달 출력 후 확인 시에만 삭제 |
| FEAT-05 | 자동 갱신 (Polling) | - 대시보드(`/`) 및 상세 화면(`/route/:id`) 진입 시 30초마다 도착 정보 백그라운드 재조회<br>- 헤더 우측 상단 [새로고침] 아이콘 클릭 시 즉시 갱신 (클릭 시 1초간 회전 애니메이션) | - 백그라운드 갱신 중 오류 발생 시 기존 화면 데이터를 유지하고 에러 토스트만 3초간 표시 |
