## 1. 프로젝트 개요 (한눈에 보기)

### 프로젝트 목적
- 사용자의 출퇴근 동선(출발지~도착지)에 맞는 버스·지하철 복합 대중교통 최적 경로, 출발/도착 시각, 상세 정차역 정보를 제공하고, 집에서 나갈 시점에 맞춰 브라우저 알림을 주어 바쁜 출퇴근길을 돕는 웹 서비스.

### 주요 가치
- 즐겨찾는 출퇴근 경로 저장 및 빠른 조회 (`LocalStorage` 기반)
- 수도권(서울/경기/인천) 버스 및 지하철 실시간 도착 예정 시간, 출발 시각, 예상 도착 시각 확인
- **복합 경로 추적**: 버스와 지하철을 환승하는 복합 경로 지원 및 상세 구간별 교통수단(버스/지하철) 아이콘·이름 표기
- **정차역 상세 보기**: 탑승부터 하차까지 거치는 모든 정차역 목록 시각화
- **출발 타이밍 알림 기능**: 실시간 남은 시간을 역산하여 집에서 출발해야 할 시점(도보 소요 시간 기준)에 브라우저 알림 전송

### 타겟 사용자
- 매일 정해진 버스·지하철 복합 환승 출퇴근 경로를 이용하며, 탑승 및 하차 타이밍을 정확히 맞추고 싶어 하는 직장인 및 학생

## 2. 사용자와 사용 시나리오

### 사용자 페르소나
- **직장인 김출근 (30세)**: 매일 아침 집에서 회사까지 버스와 지하철을 환승해 출근함. 집을 나서기 전 실시간 도착 정보를 보고 나가는 타이밍을 잡고 싶어 함.

### 사용자 시나리오
1. **경로 설정**: 사이트 접속 후 자주 가는 출발지와 도착지를 입력하여 브라우저에 저장한다.
2. **실시간 정보 확인**: 메인 화면에서 저장된 출퇴근 경로 카드를 누르면 현재 시각 기준 최적 경로와 다음 도착 차량의 남은 시간을 확인한다.
3. **새로고침**: 도착 정보는 30초마다 자동 갱신되거나 새로고침 버튼으로 갱신할 수 있다.

### 2. 실시간 도착 정보 객체 모델 (런타임 메모리 상태)
```typescript
interface TransitSegment {
  type: 'walk' | 'subway' | 'bus';
  name: string;
  startStation?: string;
  endStation?: string;
  lineNo?: string;
  stationName?: string;
  stations: string[];
}

interface TransitArrivalInfo {
  routeId: string;
  departureTime: string;
  arrivalTime: string;
  remainingMinutes: number;
  remainingSeconds: number;
  isImminent: boolean;
  lastUpdated: string;
}
```

- **시나리오 1: 상세 조건(지하철 노선번호 및 버스 정류소명) 지정 후 경로 검색 및 저장 (SCR-02 -> SCR-01)**
  - **Given**: 사용자가 `/search` 페이지에 접속해 있다.
  - **When**: 지하철 역명 입력 후 노선번호를 선택하고, 버스 정류소명을 검색하여 정류소를 선택한 뒤 [저장하기] 버튼을 클릭한다.
  - **Then**: `/` (메인 화면)으로 이동하며, LocalStorage에 선택한 노선번호와 정류소명이 반영된 경로 카드가 표시된다.

- **시나리오 2: 상세 경로 내 정차역 및 노선/정류소명 확인 (SCR-03)**
  - **Given**: 메인 화면에서 경로 카드를 클릭하여 상세 페이지(`/route/route_1`)에 진입했다.
  - **When**: 상세 화면의 대중교통 구간별 노선번호와 정류소명, 정차역 목록 영역을 확인한다.
  - **Then**: 지하철 노선번호와 버스 정류소명이 정확히 표기되어 있으며 거쳐가는 모든 정차역 목록이 표시된다.

- **시나리오 3: 출발 타이밍 알림 푸시 (SCR-03)**
  - **Given**: 도보 소요 시간이 '7분'으로 설정되어 있고 알림 스위치가 'On' 상태이다.
  - **When**: 실시간 첫 탑승 차량 도착 남은 시간이 '7분' 이하가 된다.
  - **Then**: 브라우저 알림으로 `"[경로명] 지금 출발하세요! 첫 번째 탑승 교통수단 도착까지 7분 남았습니다."` 메시지가 발송된다.

- **시나리오 4: 스모크 테스트 경로 검증**
  - **Given**: 앱이 Vercel에 배포되었다.
  - **When**: GET `/`, GET `/search`, GET `/route/route_1` 경로에 각각 접속한다.
  - **Then**: 세 경로 모두 200 OK 응답과 함께 해당 화면의 UI가 오류 없이 렌더링된다.
