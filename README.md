# 출퇴근 대중교통 길잡이 — 실행 가이드

이 가이드는 Node.js 환경이 익숙하지 않은 비전문가도 쉽게 '출퇴근 대중교통 길잡이' 웹 서비스를 실행하고 테스트할 수 있도록 작성되었습니다.

## 1. 사전 준비물
컴퓨터에 **Node.js (버전 20 이상)**가 설치되어 있어야 합니다.
설치 여부는 터미널(명령 프롬프트)에서 아래 명령어로 확인할 수 있습니다.
```bash
node -v
```

## 2. 프로젝트 설치 및 실행 방법

1. 프로젝트 폴더를 압축 해제한 뒤 터미널을 엽니다.
2. 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
   ```bash
   npm install
   ```
3. 개발 모드로 프로그램을 실행합니다.
   ```bash
   npm run dev
   ```
4. 화면에 나타나는 로컬 주소(예: `http://localhost:3000`)를 웹 브라우저에 입력하여 접속합니다.

## 3. 테스트 실행 방법
작성된 유닛 및 컴포넌트 테스트를 실행하려면 아래 명령어를 입력하세요.
```bash
npm run test
```

## 4. 빌드 방법
실서비스 배포를 위해 정적 파일을 생성하려면 아래 명령어를 실행합니다.
```bash
npm run build
```
